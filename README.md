# Field Scope Checklist app

Upload every file in this folder to any HTTPS web host (Azure Static Web Apps, GitHub Pages, Netlify).
Then open the address on each device and install it:
- iPad / iPhone: Safari > Share > Add to Home Screen
- Windows / Mac: Chrome or Edge > Install app icon in the address bar

Open it once while online; after that it works offline. Claims save on each device.
Move a claim between devices with Scope Report > Save claim file, then Open claim file on the other device.
The AI agent is off in this version (it needs a server); everything else works.
When you update the files, raise VERSION in sw.js so devices fetch the new version.
