# Field Scope Checklist app

Upload every file in this folder to your GitHub repository (replace the old files), or to any HTTPS web host.
Then open the address on each device and install it:
- iPad / iPhone: Safari > Share > Add to Home Screen
- Windows / Mac: Chrome or Edge > Install app

Open it once while online; after that it works offline. Claims save on each device.

Sharing a claim: Scope Report > Save claim file makes one "Claim <number>.html" file.
- On iPhone/iPad, tapping it shows the claim, scope and photos (view only).
- On a computer, double-clicking it opens the full checklist, editable, no link needed. Save there makes an updated copy.
- In this app, Scope Report > Open claim file opens it (older .json claim files open too).

When you update the files, raise VERSION in sw.js so devices fetch the new version.
